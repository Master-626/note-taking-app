# Note Taking App

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Productivity Tool](https://img.shields.io/badge/productivity-tool-green.svg)]()

A full-featured CLI note-taking application with Markdown support, tags, and full-text search.

## ✨ Features

- **Create Notes** - Quick note creation with Markdown
- **Organize** - Tags, categories, folders
- **Search** - Full-text search across all notes
- **Pinning** - Pin important notes
- **Export** - Export to HTML, PDF, JSON
- **Import** - Import from JSON
- **Rich UI** - Beautiful colored terminal output
- **SQLite** - Local persistence

## 📦 Installation

```bash
git clone https://github.com/Master-626/note-taking-app.git
cd note-taking-app
pip install .
```

## 🚀 Quick Start

```bash
# Add a note
notes add "Meeting Notes"

# List notes
notes list

# Search notes
notes search meeting
```
